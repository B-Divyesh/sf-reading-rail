How it works

Use the rail on the page you are reading

Reading Rail adds a guide over browser text. It does not replace the page.

  1. 01

    Start the rail

    Choose a line or paragraph. The rail follows readable text when the page scrolls or reflows.

  2. 02

    Set spacing for one site

    Choose original, open, or wide line and letter spacing. The setting stays local to that site.

  3. 03

    Read selected text aloud

    Use the browser voice for the current line or paragraph. Stop it with the same control.

  4. 04

    Move or leave quickly

    Use Arrow keys to move the rail. Press Escape to hide it right away.

Privacy

Keep reading content on your device

Reading Rail needs no account. It stores per-site settings in browser storage and makes no tracking requests.

Install the extension

Install Reading Rail in Chrome

Download the package, then load its folder through Chrome’s extensions page.

  1. 1

    Download the package

    Save and unzip Reading Rail.

  2. 2

    Open extensions

    Visit chrome://extensions and turn on Developer mode.

  3. 3

    Load the folder

    Choose “Load unpacked” and select the unzipped folder.
